# Build 44 — Saved level

The picture is [44-saved-level-diagram.png](44-saved-level-diagram.png). Click that file to see the drawing.

This plan follows [01-studymaster-agent.md](01-studymaster-agent.md). Each saved study already shows the goal, the minutes, the pieces, the site, and the day. This build names who that pack was written for.

## What this build does

Under the goal, each saved study names the level saved with that pack. A beginner pack says **For a beginner**. An intermediate pack says **For an intermediate learner**. An advanced pack says **For an advanced learner**. A pack with no level keeps that line off.

Showing the line reads this computer and does not call OpenAI. **Find a study** does not read this line yet.

## Left alone

The reader, agents, three sentence checks, catalog, finder, pack size, and `.env` stay unchanged. The title stays **StudyMaster AI**.
