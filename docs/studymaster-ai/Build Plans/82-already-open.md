# Build 82 — Already open

The picture is [82-already-open-diagram.png](82-already-open-diagram.png). Click that file to see the drawing.

This plan follows [01-studymaster-agent.md](01-studymaster-agent.md). Opening a saved study fills the form. This build says the pack is already open.

## What this build does

While a pack is open, a line under **Study this page** says **This pack is already open. A new pack starts when the page, the level, the goal, or the minutes change.**

The same page, level, goal, and minutes open the saved pack again. **Start over** clears the line. The saved list and **About this pack** stay as they are.

Showing the line reads this computer and does not call OpenAI.

## Left alone

The reader, agents, three sentence checks, catalog, pack size, and `.env` stay unchanged. The title stays **StudyMaster AI**.
