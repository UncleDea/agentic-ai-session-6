# Planning rule

Before any build, add the next numbered Markdown file in this folder and wait for confirmation. Write the plan first. Write the code after the plan is confirmed.

Plans stay in this folder after the code is written.

## File names

Use two digits, a hyphen, and a short title:

1. `00-planning-rule.md` is this rule.
2. `01-studymaster-agent.md` is the plan for the whole agent.
3. [end-to-end-agentic-diagram.png](end-to-end-agentic-diagram.png) is the picture of the agents. [end-to-end-diagram.png](end-to-end-diagram.png) is the learner-step picture. [end-to-end-diagram.md](end-to-end-diagram.md) is the written copy. None of these files has a build number.
4. The next build uses the next free number, such as `02-safe-page-reading.md`.

## When a build is ready to start

1. Add its plan file here.
2. Stop and wait for confirmation.
3. Implement only what that file describes.
4. Leave the plan in this folder.
