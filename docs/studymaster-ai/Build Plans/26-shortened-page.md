# Build 26 — Shortened page

The picture is [26-shortened-page-diagram.png](26-shortened-page-diagram.png). Click that file to see the drawing.

This plan follows [01-studymaster-agent.md](01-studymaster-agent.md). The reader already stops at 60,000 characters. This build tells the learner when that happens.

## What this build does

When the kept text is longer than the limit, the top of the pack says **This page was shortened to 60,000 characters.** That line is saved with the outline, so opening the study later still shows it.

A page that fits, including the data loss prevention article, does not show the line. The line is not guessed from the length of the saved text.

## Left alone

The size limit stays 60,000 characters. The agents, the catalog, and the saved studies stay unchanged. The title stays **StudyMaster AI**.
