## What this build does

The guide gives the PowerShell commands that start the page, then the clicks for one starter article:

1. Open http://localhost:8501. The title is **StudyMaster AI**.
2. In **Starter article**, choose **Data protection: Learn about data loss prevention**.
3. Press **Study this page** once.

It also says how to tell that the OpenAI key is ready, that a LinkedIn line is only a reference, and which three buttons are the paid calls.
