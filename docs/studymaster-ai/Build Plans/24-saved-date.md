# Build 24 — Saved date

The picture is [24-saved-date-diagram.png](24-saved-date-diagram.png). Click that file to see the drawing.

This plan follows [01-studymaster-agent.md](01-studymaster-agent.md). Each saved study already stores the time it was saved. This build shows that day on the list.

## What this build does

Under each saved title, the goal line stays. A second line says **Saved October 25, 2026**, using the day on this computer. Two studies with similar titles show their own days.

**Find a study** still matches the title and the goal line. **Open study** and **Delete** stay on each row. Showing the day does not call OpenAI.

## Left alone

The reader, agents, catalog, sentence check, Start over, progress box, grader, and `.env` stay unchanged. The title stays **StudyMaster AI**.
