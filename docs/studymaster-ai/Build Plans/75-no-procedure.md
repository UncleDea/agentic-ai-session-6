# Build 75 — No procedure

The picture is [75-no-procedure-diagram.png](75-no-procedure-diagram.png). Click that file to see the drawing.

This plan follows [01-studymaster-agent.md](01-studymaster-agent.md). Each saved study already ends with a line about the runbook. On these four packs that runbook is the normal note that the page has no procedure. This build uses those words.

## What this build does

Under the last line of each saved study, a pack whose runbook is only those two sentences says **This page has no procedure.** All four packs say that. The Entra pack says it under **The lesson came back empty.** The other three say it under the left-to-check line.

Typing **procedure** keeps all four packs. Typing **empty** keeps only the Entra pack, because that pack is the one whose lesson came back empty. A pack whose runbook has steps stays off a search for **procedure**.

Showing the line reads this computer and does not call OpenAI. The open pack already shows the full runbook sentences. The download stays the study text.

## Left alone

The reader, agents, three sentence checks, catalog, pack size, and `.env` stay unchanged. The title stays **StudyMaster AI**.
