# Build 46 — Open level

The picture is [46-open-level-diagram.png](46-open-level-diagram.png). Click that file to see the drawing.

This plan follows [01-studymaster-agent.md](01-studymaster-agent.md). Each saved study already says who the pack was written for. This build shows that same line on the open pack.

## What this build does

Under the title, next to the site line, the open pack names the level saved with that pack. A beginner pack says **For a beginner**. An intermediate pack says **For an intermediate learner**. An advanced pack says **For an advanced learner**. A pasted lesson still gets the line, because the level is about the learner.

Opening a saved study reads this computer and does not call OpenAI. The download stays the study text.

## Left alone

The reader, agents, three sentence checks, catalog, finder, pack size, and `.env` stay unchanged. The title stays **StudyMaster AI**.
