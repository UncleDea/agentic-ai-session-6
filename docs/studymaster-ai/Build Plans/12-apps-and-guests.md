## What this build does

The group name is **Apps and guests**. Each article has a Learn URL and one goal sentence. The LinkedIn address is empty, so the page does not show a reference link for these three.

Choosing one fills **Page link** and **Goal**. The learner still presses **Study this page**. The choice does not call OpenAI.

These Learn URLs answered as public pages on October 25, 2026:

| Title | Learn page | Goal sentence |
| --- | --- | --- |
| What is single sign-on in Microsoft Entra ID? | `https://learn.microsoft.com/en-us/entra/identity/enterprise-apps/what-is-single-sign-on` | Explain how single sign-on works in Microsoft Entra ID. |
| Microsoft Entra B2B best practices | `https://learn.microsoft.com/en-us/entra/external-id/b2b-fundamentals` | Explain the recommended practices for guest users. |
| Plan a B2B collaboration deployment | `https://learn.microsoft.com/en-us/entra/architecture/secure-external-access-resources` | Explain how to plan collaboration with guest users. |
