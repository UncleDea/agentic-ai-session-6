# Build 32 — Show sections while writing

The picture is [32-show-while-writing-diagram.png](32-show-while-writing-diagram.png). Click that file to see the drawing.

This plan follows [01-studymaster-agent.md](01-studymaster-agent.md). A new pack shows each finished section during the wait.

## What this build does

While a new pack is written, the page keeps the step names. When the outline is finished, the outline appears. When the study is finished, the study appears under it, then the lesson, the lab, the project, and the runbook. A section that fails shows its error and the later sections still appear.

When the pack is ready, that waiting text folds away. The finished pack still leads with the first question. Opening a saved study does not play the sections again. The hidden lesson answer stays off the page.

## Left alone

The three checks stay. **Rewrite lesson** stays the button for an empty lesson. The title stays **StudyMaster AI**.
