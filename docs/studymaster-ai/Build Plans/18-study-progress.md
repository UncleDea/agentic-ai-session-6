# Build 18 — Study progress

The picture is [18-study-progress-diagram.png](18-study-progress-diagram.png). Click that file to see the drawing.

This plan follows [01-studymaster-agent.md](01-studymaster-agent.md). Pressing **Study this page** already writes the pack in order. This build names that order on the page.

## What this build does

The status box updates through these messages:

1. Checking the link.
2. Reading the page. A pasted lesson says **Using the pasted lesson.**
3. Opening the saved pack, when that same page was already saved. This is the last step.
4. Writing the outline, then the study, lesson, lab, project, and runbook.

A finished pack ends with **Study pack ready.** An error shows the message the page already shows. **Rewrite** keeps its own one-line spinner. The title stays **StudyMaster AI**.

## Left alone

The reader, agents, catalog, grader, Delete button, and `.env` stay unchanged.
