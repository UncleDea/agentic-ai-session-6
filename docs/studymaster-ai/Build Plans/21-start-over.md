# Build 21 — Start over

The picture is [21-start-over-diagram.png](21-start-over-diagram.png). Click that file to see the drawing.

This plan follows [01-studymaster-agent.md](01-studymaster-agent.md). A finished pack stays on the page, and the form stays filled. This build adds a button that clears that screen.

## What this build does

**Start over** sits under the study form. One press clears the open pack from the screen. The same press clears **Page link**, **Article text**, and **Goal**. **Starter article** returns to **Paste my own link**. **Reading goal** returns to **No reading goal**. **Level** returns to **Beginner**. **Minutes** returns to **20**.

The pack remains under **Saved studies**. **Find a study** keeps the words already typed. The button does not call OpenAI.

## Left alone

The reader, agents, catalog list, sentence check, progress box, Delete button, grader, and `.env` stay unchanged. The title stays **StudyMaster AI**.
