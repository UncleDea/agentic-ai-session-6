## What this build does

The group name is **Devices**. Each article has a Learn URL and one goal sentence. The LinkedIn address is empty, so the page does not show a reference link for these three.

Choosing one fills **Page link** and **Goal**. The learner still presses **Study this page**. The choice does not call OpenAI.

| Title | Learn page | Goal sentence |
| --- | --- | --- |

| Require device compliance with Conditional Access | `https://learn.microsoft.com/en-us/entra/identity/conditional-access/policy-all-users-device-compliance` | Explain how Conditional Access can require a compliant device. |
